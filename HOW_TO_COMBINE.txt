Each member folder has the same paths as the final GitHub repo.
To run the full project, copy the content of all 4 folders into one folder.
Then run the commands in Member_1_Documentation_Lead/README.md.

Member 1 (Documentation Lead): README.md, src/data_prep.py, data/processed_data2.csv
Member 2 (PPT Lead):           src/eda.py
Member 3 (Setup Lead):         requirements.txt, run_all.py, src/train.py, src/config.py, src/__init__.py, .gitignore
Member 4 (Video Lead):         src/evaluate.py

Each member must commit their own files from their own GitHub account.
